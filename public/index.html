60-SECOND TRIAGE

Periksa kesehatan

curl -i "$EVOPAY_URL/health/ready"

Jika readiness gagal, jangan restart loop. Ikuti Runbook Database down.

CALLBACK FAILURE

Inspect → test → replay

Perbaiki endpoint Site, jalankan Test webhook, lalu replay DEAD_LETTER. Handler wajib idempotent berdasarkan delivery ID.

TOKOPAY DELAY

Hentikan create baru

Aktifkan Maintenance Mode untuk Site terdampak. Jangan tandai payment FAILED hanya karena timeout.
