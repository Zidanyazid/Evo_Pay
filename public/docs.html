01 / AUTHENTICATION

Satu key, akses yang terkontrol.

Kirim API key merchant melalui Bearer authentication. Simpan key hanya di server—jangan pernah menaruhnya di browser atau aplikasi mobile.

HTTP
Authorization: Bearer np_live_xxx
Content-Type: application/json
Idempotency-Key: order-10001
02 / PAYMENT METHODS

26 channel pembayaran Tokopay.

Ambil metode merchant dengan GET /api/v1/payment-methods. Setiap item memuat biaya admin, penanggung biaya, settlement, minimum, maksimum, status aktif, dan kebutuhan pendaftaran.

Virtual Account · 10 channel

BRIVA, BCAVA, BNIVA, MANDIRIVA, PERMATAVA, CIMBVA, DANAMONVA, BSIVA, BNCVA, PERMATAVAA

E-Money · 11 channel

SHOPEEPAY, GOPAY, DANA, LINKAJA, VIRGO, ASTRAPAY, OVOPUSH, DANA_REALTIME, SHOPEEPAY_REALTIME, GOPAY_REALTIME, OVOPUSH_REALTIME

QRIS · 3 channel

QRIS, QRISREALTIME, QRIS_CUSTOM. QRIS Custom memerlukan pendaftaran merchant.

Retail · 2 channel

ALFAMART, INDOMARET

Biaya pembeli menaikkan total_amount; biaya merchant mengurangi net_amount. Error operasional: PAYMENT_METHOD_UNKNOWN, PAYMENT_METHOD_DISABLED, PAYMENT_METHOD_REGISTRATION_REQUIRED, dan PAYMENT_AMOUNT_OUT_OF_RANGE.

04 / WEBHOOKS

Ketahui pembayaran secara real-time.

NexusPay mengirim event ke callback merchant. Balas HTTP 2xx dengan cepat dan deduplikasi event berdasarkan payment ID.

Golden ruleJangan proses produk dari redirect browser. Hanya proses setelah webhook payment.paid atau verifikasi API.
PAYLOAD
{
  "event": "payment.paid",
  "data": { "id": "pay_...", "order_id": "TOPUP-10001", "status": "PAID" }
}

06 / SECURITY

Production checklist

  • Gunakan HTTPS pada gateway dan callback.
  • Simpan secret di environment server.
  • Gunakan idempotency key untuk setiap operasi POST.
  • Validasi status dan nominal sebelum menyerahkan produk.
  • Rotasi credential secara berkala.
NexusPay Developer Platform API v1

Whitelist IP

Akses API dapat dibatasi per merchant untuk IPv4, IPv6, atau CIDR melalui dashboard Whitelist IP. Jika request berasal dari jaringan yang tidak diizinkan, API mengembalikan 403 IP_NOT_ALLOWED.

Gunakan TRUST_PROXY=1 hanya jika NexusPay berada di belakang reverse proxy tepercaya agar IP klien diteruskan secara aman.
